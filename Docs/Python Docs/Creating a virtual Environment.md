Creating a virtual environment helps in avoiding potential conflicts between different Python packages and in-build features.

On the project's root terminal run:
```bash
python -m venv <env_name>
```
- `<env_name>`: Is generally named venv

1. In VS Code to select the virtual environment press: `Ctrl + Shift + P` then, type `"Python: Select Interpreter". Select the option and click to your created environment (It will show there with your virtual environment's name).

2. To make sure that you are in virtual enviroment click: `Ctrl + ~`. There you will see `(venv)`. It indicates that you are in virtual environment. If not occurs repeat the 1st steps correctly.

> [!tip]+ TIP
> Install all the packages in (venv) only.
